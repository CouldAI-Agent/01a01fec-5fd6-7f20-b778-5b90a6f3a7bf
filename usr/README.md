# Private AI Financial Assistant

A secure, private, intelligent financial research and opportunity assistant that helps manage, verify, and discover financial opportunities while protecting against scams.

## Overview
This application functions as a private AI assistant with its own secure identity. It performs web research, scam detection, financial analysis, and investment tracking. It includes a comprehensive Permission Center and Security Center to ensure the user retains complete control over sensitive data and automated actions.

## Features
- **AI Chat Interface**: A secure text and voice chat interface to interact with the AI assistant.
- **Financial Dashboard**: Overview of opportunities, income, investments, and risk analyses.
- **Local Memory Center**: A persistent, offline, local memory system configured for SD-card storage with encryption support.
- **Permission Center**: Detailed tracking and toggle controls for all access vectors (network, SD card, trading, background ops).
- **Security Center**: Encrypted API-key storage, audit logs, rate limiting, and master controls.
- **Scam Detection Module**: Built-in 0-100 risk scoring to protect against phishing and fraud.

## Tech Stack
- Flutter (Cross-platform: Android, Web, Windows)
- Material 3 (Dark Mode enabled)

## Setup & Run
1. Ensure Flutter SDK is installed.
2. Run `flutter pub get`
3. Run `flutter run` on your preferred device (Android is optimized for SD-card memory).
